# מי המתחזה?

משחק מסיבה בעברית לטלפון אחד. מכניסים שמות, בוחרים קטגוריות ומספר מתחזים, ומעבירים את הטלפון מיד ליד: כל אחד רואה בפרטיות את המילה המשותפת, או הודעה שהוא המתחזה יחד עם רמז. אחרי שכולם ראו את התפקיד שלהם, המסך מכריז מי פותח את השיחה (הגרלה שווה בין כל השחקנים, מתחזה או לא), מניחים את הטלפון ומשחקים בשיחה.

- עברית בלבד, ימין-לשמאל, ללא חשבונות, פרסומות או שרת.
- פועל לחלוטין בצד הלקוח ומתאים לאחסון סטטי.
- 22 קטגוריות וכ־4,100 מילים, כולל קטגוריית ״שחקני כדורגל״ עם כמעט 1,400 שחקנים. לכל מילה שלושה רמזים לפחות, כולם מקומיים.
- הגופנים (Secular One, Rubik) מצורפים לפרויקט; אין תלות בשירות גופנים חיצוני. האייקונים מספריית Lucide.

## הרצה מקומית

דרישות: Node.js 20 ומעלה.

```bash
npm install
npm run dev
```

הכתובת תודפס במסוף (בדרך כלל `http://localhost:5173`). כדאי לבדוק במצב תצוגת מובייל בכלי המפתחים.

## פריסה לאחסון סטטי

התיקייה `dist/` היא כל מה שצריך. אין שרת, מסד נתונים או מפתחות API.

- **Netlify / Vercel / Cloudflare Pages:** פקודת בנייה `npm run build`, תיקיית פלט `dist`.
- **Render:** הקובץ `render.yaml` בשורש מגדיר אתר סטטי (התוכנית החינמית). ב-Render בוחרים **New → Blueprint**, מחברים את הריפו, והפריסה מתבצעת אוטומטית בכל דחיפה ל-`main`.
- **GitHub Pages או כל נתיב-משנה:** בונים עם בסיס מותאם, למשל:

```bash
VITE_BASE=/my-repo/ npm run build
```

ב-Windows PowerShell: `$env:VITE_BASE="/my-repo/"; npm run build`.

האפליקציה משתמשת במסך יחיד ללא ניתוב, ולכן אין צורך בהגדרות rewrite. הקובץ `public/manifest.webmanifest` מאפשר "הוספה למסך הבית" בטלפונים.

## מבנה הקוד

```
src/
  copy/he.ts              כל הטקסטים בעברית במקום אחד
  data/
    categories.ts         21 הקטגוריות (מזהה, שם, גוון ויזואלי)
    words/<category>.ts   זוגות מילה ורמז לכל קטגוריה
    words/index.ts        איחוד הספרייה
  game/
    rules.ts              חוקי המתחזים (מקסימום, קיצוץ, בדיקת התחלה)
    random.ts             אקראיות ללא הטיה (Fisher–Yates, בחירה מובחנת)
    words.ts              בחירת מילה, זיכרון מילים בסבבים קודמים
    round.ts              יצירת סבב והקצאת תפקידים לפי מזהי שחקנים
    dealReducer.ts        מכונת המצבים של חלוקת התפקידים
    setupReducer.ts       ניהול השחקנים וההגדרות
  storage/setupStorage.ts שמירה מגורסת ב-localStorage עם אימות
  components/             רכיבי ממשק, קמע (עיניים, מסכה), אייקוני קטגוריות
  screens/                מסך ההגדרות, גיליונות השחקנים והקטגוריות, זרימת החלוקה
```

הסבב הפעיל (המילה, הרמז, מי המתחזה, ההתקדמות) נשמר בזיכרון בלבד. רענון הדף מחזיר למסך ההגדרות עם השחקנים והבחירות השמורים.

## הוספת מילים ורמזים

כל קטגוריה היא קובץ ב-`src/data/words/`, למשל `src/data/words/food.ts`:

```ts
export const foodWords = defineWords('food', [
  ['פיצה', 'חבורה', 'ספה', 'חלוקה'],
  ['פלאפל', 'צהריים', 'תור', 'רחוב'],
]);
```

כל שורה היא `[מילה, רמז, רמז, רמז, ...]`: מילה אחת ולפחות שלושה רמזים. בכל סבב המתחזים מקבלים רמז אחד מהרשימה, שנבחר באקראי. המזהה של כל רשומה נגזר מהקטגוריה ומהמילה עצמה, ולכן אפשר להוסיף ולסדר מחדש בחופשיות, כל עוד אין שתי שורות עם אותה מילה.

כללי כתיבה לרמז:

- רמז הוא אסוציאציה קצרה (מילה עד שלוש) שמתאימה גם לכמה מילים אחרות באותה קטגוריה: הקשר, תחושה, מקום, חפץ נלווה.
- רמז לא יכול להיות ״פיתיון״: לא המילה או חלק ממנה, לא תרגום או שם נרדף, ולא תכונה מזהה (להוקי הרמז ״קרח״ פסול, ״מקל״ או ״קבוצה״ בסדר).
- שלושת הרמזים של מילה מגיעים מזוויות שונות, ומגוונים את הרמזים בתוך הקטגוריה.
- רמזים תמיד בעברית, גם כשהמילה באנגלית. בתוך טקסט עברי משתמשים בגרש ׳ ובגרשיים ״, לא בגרשים לטיניים.

כללי שמות:

- מותגים, חברות, משחקי מחשב, גיבורי-על ולהקות בינלאומיות נכתבים באנגלית כפי שהמותג כותב אותם (Nike, BMW, Overwatch, Batman, Coldplay). גם שחקני הכדורגל נכתבים בכתיב הלטיני המקובל (Cristiano Ronaldo, Pavel Nedvěd), והרמזים שלהם הם נבחרת, עמדה, קבוצה או תקופה.
- מותגים ישראליים עם לוגו עברי (במבה, תנובה, אל על), שמות של אנשים, כותרי סרטים וסדרות, מקומות ומונחים כלליים נשארים בעברית.

אחרי כל שינוי בתוכן מריצים:

```bash
npm run validate:words
```

הסקריפט בודק לכל קטגוריה: לפחות שלושה רמזים לכל מילה, אין כפילויות מילים, אין רמז שמכיל את המילה או מוכל בה, אין שורש משותף בין מילה לרמז, אין גרשים לטיניים בעברית, ושונות מספקת של רמזים. הבדיקה `src/data/words.test.ts` מוודאת את אותם כללים ב-`npm test`, יחד עם ממוצע של לפחות 100 מילים לקטגוריה. איכות הרמז עצמה עדיין דורשת קריאה אנושית.

### הוספת קטגוריה חדשה

1. מוסיפים מזהה חדש ל-`CategoryId` ב-`src/data/types.ts`.
2. מוסיפים רשומה ל-`CATEGORIES` ב-`src/data/categories.ts` (שם בעברית וגוון).
3. יוצרים קובץ מילים חדש ב-`src/data/words/` ומרשמים אותו ב-`src/data/words/index.ts`.
4. בוחרים אייקון Lucide וממפים אותו ב-`src/components/icons/CategoryIcon.tsx`.
5. מעדכנים את רשימת השמות בבדיקת הנתונים.
